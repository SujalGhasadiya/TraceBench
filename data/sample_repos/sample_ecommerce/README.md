# Sample Multi-Language E-Commerce Microservices

This sample repository demonstrates TraceBench's unified multi-language indexing across:
1. Python (`services/tax_calculator.py`, `services/order_service.py`)
2. JavaScript (`auth/jwt_validator.js`)
3. TypeScript (`types/user.ts`)
4. Java (`payments/PaymentProcessor.java`)
5. C (`network/socket_server.c`)
6. C++ (`db/connection_pool.cpp`)
7. Go (`server/router.go`)
8. Rust (`cache/memory_cache.rs`)
9. PHP (`controllers/UserController.php`)

Used for automated retrieval evaluation, citation verification, and interactive graph exploration.
